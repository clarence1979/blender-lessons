▎ 02 — The science behind it

Smoke is just a 3D grid of cells.

Real smoke is trillions of microscopic particles drifting on air currents. Way too many to simulate. So we cheat. Blender chops 3D space into a voxel grid — like a Minecraft world made of invisible cubes — and tracks density, temperature, and velocity in each cell. Every frame, those values flow into neighbouring cells based on physics rules. That's smoke.

The four ingredients ↤

Density — how thick the smoke is in each cell. Black squares = packed full of smoke.
Heat — temperature controls buoyancy. Hot cells rise. Cold cells stay put or sink.
Velocity — direction and speed of motion in each cell. The arrows that push smoke around.
Vorticity — how swirly the motion is. Real smoke curls. Without this, your smoke looks like a boring straight line.
▎ 03 — The two objects you need

Domain. Flow. That's it.

Every smoke simulation in Blender needs exactly two objects with physics turned on. Get these wrong and your scene is just two cubes sitting there judging you.

📦

The Domain

The invisible box where physics happens. Smoke can only exist inside this box. Make it bigger = more space for smoke to spread.

Type: Domain · Gas
💨

The Flow

The source. The object the smoke pours out of. This is what you see in the final render — its shape influences the smoke pattern.

Type: Flow · Gas
▎ 04 — Lab 17A · The basic plume

Build your first smoke simulation.

Time to make the default cube finally do something useful. Follow each step. Don't skip the bake.

Duplicate the default cube

Open a new Blender file. Click the cube. Press Shift+D to duplicate it. Right-click to drop the copy at its current position. You should now see two cubes overlapping.

Rename one cube to "Domain"

In the Outliner (top-right), double-click one cube and rename it Domain. This is the box that will hold all the smoke physics.

Make it the Domain (Gas)

With the Domain selected, open Physics Properties (the bouncing-ball icon 🔵 on the right toolbar). Click Fluid. Set Type to Domain and Domain Type to Gas.

Set up the Flow object

Click the other cube. Open Physics Properties → Click Fluid. Set Type to Flow and Flow Type to Smoke. This cube is now a smoke emitter.

Resize the Domain so it covers everything

Select the Domain, press G to grab and lift it up. Press S to scale it bigger — it needs to completely contain the Flow cube AND have room above for smoke to rise. Think of it like a fish tank: the smoke can't escape outside the glass.

🚦 Checkpoint — first test!

Press Spacebar (or the Play button at the bottom). You should see grey smoke rising from the inner cube. If you see nothing, your Domain is probably too small or doesn't enclose the Flow cube. Fix that and try again.

Bump up the resolution

Select the Domain. In Physics Properties, find Resolution Divisions. Default is 32 (blocky and pixelated). Set it to 54 for noticeably smoother smoke. Press play again. Look at that detail.

Add initial velocity (give the smoke a push)

Click the inner cube (the Flow object). In its Fluid settings, find Initial Velocity. Set the X-axis to 5 m/s. Press play — the smoke now blasts sideways instead of just rising. Like a side-on rocket.

BAKE the simulation

Playing in real-time recalculates every frame. Baking saves the whole simulation to disk so playback is smooth and you can render it. Select the Domain → Physics Properties → scroll to Cache → click Bake All. Wait. Don't touch anything. ☕

📝 Mini-challenge before submitting

Replace the Flow cube with a different shape — maybe a cone, sphere, or monkey head (Suzanne). Bake again. Question to think about: does the smoke take the shape of the object? What changes? What stays the same?

Save and submit

Save your file as Lab 17A.blend (File → Save As). Upload to SEQTA before moving on to Lab 17B.

▎ 06 — Lab 17B · The artistic plume

Now make it gorgeous.

Same setup, different vibe. We're swapping the Flow object for something curvier and dialling in the parameters for a slow, swirling, atmospheric look — the kind of smoke you'd see in a moody film scene.

Why does shape matter? The Flow object's geometry determines where smoke gets injected into the Domain. A torus has a hole — smoke pours through it.

Cube

Smoke = column. Boring but reliable.

Torus 🍩

Smoke = ring/donut shape. Use this!

Sphere

Smoke = round plume. Soft & volcanic.

Cone

Smoke = tapered plume. Rocket vibes.

Replace the Flow cube with a Torus

Select the inner cube and delete it (X). Add a new Torus: Add → Mesh → Torus. With the Torus selected, repeat the Flow setup: Physics Properties → Fluid → Type: Flow → Flow Type: Smoke. Position it inside the Domain.

First test

Press play. Notice the smoke now matches the donut shape as it rises — there's a hole through the centre and the plume curves outward instead of going straight up like the cube did.

Drop the heat to zero

Select the Domain. In Fluid settings, find Heat (under the Smoke section) and set it to 0. The smoke now rises much more slowly and smoothly — no aggressive heat-driven buoyancy.

Crank the vorticity to 0.1

Still in the Domain, find Vorticity. Set it to 0.1. This adds beautiful little curls and swirls to the smoke — like real cigarette smoke or steam off coffee. Detail without chaos.

Switch Domain Type to "All"

In the Domain settings, change Type from "Gas" to All. This means the simulation tracks both smoke and fire data (even though we're not using fire). Set Resolution Divisions to 150. Yes, 150. This will be slow. That's the point.

⚠️ Heads up: this will take time

Resolution 150 means the voxel grid is much denser. The bake might take 5–15 minutes depending on your PC. Don't quit Blender. Don't switch users. Don't slam the laptop shut. Let it cook. 🍳

Set the End Frame to 100

Bottom of the screen, find the End Frame field (probably says 250). Change it to 100. This shortens the simulation to 100 frames so the bake finishes faster.

Bake (optional but recommended)

Domain → Physics Properties → Cache → Bake All. While it bakes, sketch out your next scene idea, or stretch.

🎬 Save and submit

Save as Lab 17B.blend and upload to SEQTA. Bonus marks for an interesting render with lighting (F12 to render).

▎ 07 — The 6 words that matter

Memorise these. Quiz uses them all.

Domain

The invisible bounding box where the physics simulation runs. Smoke can't exist outside it.

Flow

The object that emits smoke. Its shape influences the smoke's appearance.

Resolution

The voxel grid density. Higher = more detail = slower to compute.

Vorticity

How swirly the smoke is. Real smoke is never a straight line.

Heat

Temperature in cells. Drives buoyancy — hot smoke rises faster.

Bake

Pre-calculate the entire simulation and save it to disk. Required for smooth playback & rendering.
