BSDF — Making Materials Look Real

Today you're going to colour a Blender file so it looks convincing in the real world. The secret isn't the colour — it's how the surface reacts to light.

Learning Intentions

  • Understand what BSDF means and why it matters for realism.
  • Identify the real-world material an object is made of by looking at it.
  • Apply the correct Principled BSDF settings to match that material.

Success Criteria

  • I can explain what reflect and absorb mean in shading.
  • I have given every object in the scene a material that matches what it would be made of.
  • My render looks believable — a metal looks metal, plastic looks plastic, glass looks glass.

1 What is BSDF?

BSDF stands for Bidirectional Scattering Distribution Function. That's a mouthful, so think of it this way:

A BSDF is a set of rules that tell Blender how light should behave when it hits a surface — how much gets reflected, how much gets absorbed, and how much passes through.

Every real-world material behaves differently:

  • A mirror reflects almost everything.
  • A black rubber tyre absorbs almost everything.
  • A glass window lets most light pass through and reflects a little.
  • A wooden table scatters light softly in many directions.

In Blender, we control all of this through the Principled BSDF shader — a single powerful node that can imitate almost any real-world material if you know which sliders to move.

2 The Properties That Matter

Open the Shading workspace and select any object. You'll see a Principled BSDF node. These are the sliders you'll use most often today:

Base Color
colour picker
The underlying colour of the material when lit normally.
Metallic
0.0 → 1.0
Is it metal or not? Use 0 for almost everything. Use 1 for pure metals.
Roughness
0.0 → 1.0
How polished is it? 0 = mirror-smooth, 1 = completely matte and diffused.
IOR (Index of Refraction)
1.0 → 2.5
How much light bends going through it. Glass ≈ 1.45, water ≈ 1.33, diamond ≈ 2.4.
Transmission
0.0 → 1.0
How much light passes through the surface. Use for glass, water, clear plastic.
Emission
colour + strength
Does it give off light? Use for screens, bulbs, lava, glow sticks.

4 The Workflow

Before you touch a single slider in Blender, stop and look. Every object in your scene needs this same three-step decision:

Observe the object What shape is it? What's it being used for? A cup, a table leg, a bolt, a lampshade?
Decide what it's made of In real life, what would this object actually be? Metal? Wood? Ceramic? Plastic? Glass?
Apply the matching material in Blender Select the object → go to the Material Properties tab → add a new material → adjust the Principled BSDF settings using the cheat sheet below.
Don't skip the "what is it made of" question! A wooden bowl and a metal bowl are the same shape but need completely different BSDF settings.

5 Material Cheat Sheet

Starting points for the most common materials. These aren't rules — experiment and tweak until it looks right.

Brushed Steel

Metallic: 1.0
Roughness: 0.35
Base Color: light grey

Polished Gold

Metallic: 1.0
Roughness: 0.1
Base Color: warm yellow

Plastic

Metallic: 0.0
Roughness: 0.4
IOR: 1.45

Wood

Metallic: 0.0
Roughness: 0.7
Base Color: brown + texture

Clear Glass

Transmission: 1.0
Roughness: 0.0
IOR: 1.45

Rubber

Metallic: 0.0
Roughness: 0.9
Base Color: near-black

Fabric / Cloth

Metallic: 0.0
Roughness: 0.8
Sheen: 0.3

Ceramic

Metallic: 0.0
Roughness: 0.2
IOR: 1.5

Light Source

Emission: warm colour
Strength: 5.0+
Base Color: match emission
