// 01 • Understanding Fluid Simulation

What is Fluid Simulation?

Fluid simulation is a branch of physics simulation where a computer calculates how liquids (or gases) move, splash, and settle — frame by frame. It's used in blockbuster movies, video games, and even engineering software.

Think of it like a slow-motion video of a glass of water being knocked off a table — except the computer is drawing every single droplet from scratch using maths.
📦

Domain

The invisible "container" that defines the boundaries of your simulation. Fluid can only exist inside the domain.

💧

Flow Object

The object that produces fluid. It's where the water comes from — like a tap or a dropped ice cube.

🔄

Baking

Pre-calculating every frame of the simulation. Blender works it all out and saves the result so you can play it back smoothly.

🎚️

Resolution

How detailed the simulation is. Higher resolution = more realistic but takes longer to bake. Like pixels in an image.

// 02 • Flow Behaviours Explained

Inflow vs Geometry

When you set up a flow object in Blender, you choose a Flow Behaviour. The two main options produce very different results:

PropertyInflowGeometry
What it doesContinuously pours fluid from the object — like an open tap.The object itself becomes a volume of fluid — like dropping an ice cube into a pool.
Real-world analogy🚿 A showerhead running🧊 An ice cube dropped into water

Inflow = a tap that never stops running. Geometry = dropping a water balloon on the ground. Same engine, completely different results!

// 04 • How It Fits Together

Domain + Flow Object

The flow object must sit inside the domain — otherwise Blender has no idea where to simulate the fluid. Think of the domain as a fish tank — the water can only exist inside it.

If the flow object is outside the domain, nothing will happen — it's like trying to fill a glass while pouring water beside it.
// 05 • Lab Walkthrough

Step-by-Step Guide

Follow these steps in Blender to create your own fluid simulation. If you get stuck, check the tip boxes.

1

Set Up the Scene

Open a new file in Blender. Delete the default cube (X), then add a fresh one via Add → Mesh → Cube. Switch to Solid Shading mode.

2

Duplicate the Cube

Press Shift+D to duplicate, then move the copy to the right. You now have two cubes — one will be the flow object, the other will be the domain.

3

Create the Domain

Select the right cube. In the Properties panel, go to Physics → Fluid. Set Type: Domain and Domain Type: Liquid. Rename it "Domain" in the Scene Collection.

⚠️ The domain cube will change appearance — this is normal!
4

Scale the Domain

Toggle X-Ray (Alt+Z) so you can see through objects. Press S to scale and G to grab — make the domain large enough to completely surround the other cube.

⚠️ The flow cube MUST be fully inside the domain or nothing will work!
5

Set Up the Flow Object

Click the inner cube. Go to Physics → Fluid. Set Type: Flow, Flow Type: Liquid, and Flow Behaviour: Geometry (or Inflow — experiment with both!).

6

Configure the Cache

Select the Domain object. Scroll down to the Cache section. Set Type: All and End: 100. Also set Resolution Divisions: 50 for a good balance of quality and speed.

7

Bake & Play!

Click Bake All and wait for Blender to calculate the simulation. Once complete, turn off X-Ray and press Play (spacebar) to watch your fluid in action. Hide the inner cube's visibility for a cleaner result.

⏳ Baking can take a few minutes — be patient!
// 06 • Common Mistakes

Troubleshooting

Fluid sims can be tricky. Here are the most common issues and how to fix them:

You probably haven't baked the simulation yet. Select the Domain, scroll to Cache, and click "Bake All". Fluid sims need to be pre-calculated before they can play back.

Check the small orientation cube in the corner of your viewport. If the scene is rotated, the gravity direction may look wrong. Rotate your view by pressing Numpad -Y to see it from the correct angle.

The flow object must be smaller than and fully inside the domain. Select the domain and press S to scale it up, then G to reposition it so the flow cube is completely enclosed. Don't forget to apply scale with Ctrl+A.

Increase the Resolution Divisions on the Domain. The default is usually 32 — try 50 or higher. Keep in mind that higher values take much longer to bake. It's like increasing the resolution of an image — more detail, but bigger file size.
