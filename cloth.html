▎ 02 — The science behind it

Cloth is just dots on springs.

Real cloth is made of millions of tangled threads — way too many to simulate. So we cheat. We treat fabric as a grid of points (vertices) connected by invisible springs (edges). Gravity pulls each point down. The springs pull neighbouring points together. Iterate this 60 times per second and — boom — that's cloth.

The recipe (look left ↤)

Vertex (point) — a tiny dot with mass. Gravity tugs it down.
Spring (edge) — wants to keep two points the same distance apart.
Pinned point — fixed in space. Like a peg holding a tea-towel.

What happens when we subdivide?

More dots = more springs = smoother, more believable folds. That's why your lab tells you to subdivide the plane three times — each subdivision adds way more vertices for the simulator to play with.

▎ 04 — Now build it in Blender

The 18-step mission. Difficulty:

Follow each step in order. Don't skip — cloth physics is fussy and one wrong click can mean your fabric falls right through the monkey's face like a ghost. Tick them off as you go.

Set the stage

Open Blender. Delete the default cube (X → Delete). Add a UV Sphere for ambience and a Plane for the floor: Add → Mesh → Plane.

Scale that plane up

With the floor plane selected, hit S and drag outward. Make it a proper floor — at least 5–10x bigger.

Summon the monkey 🐵

Add → Mesh → Monkey. Suzanne (Blender's mascot) appears. She's our collision target.

Add the cloth plane

Add another Plane. Press G then Z and lift it directly above Suzanne. This is the soon-to-be cloth.

Enter Edit Mode

With the upper plane selected, press Tab (or pick Edit Mode from the dropdown). We need to give the cloth more vertices so it can actually fold.

First subdivide

Right-click → Subdivide. In the bottom-left "Subdivide" panel, set Number of Cuts = 10. Your plane is now a 11×11 grid. Way more bendy.

Back to Object Mode

Tab again to exit Edit Mode.

Make the plane behave like cloth

Open the Physics Properties panel (looks like a bouncing blue ball 🔵). Click Cloth. The plane is now officially fabric.

Make Suzanne solid

Click on Suzanne (the monkey). In Physics Properties, click Collision. Without this, the cloth would phase right through her like a hologram.

🚦 Checkpoint — first test!

Press Spacebar (or the Play button at the bottom). Watch the cloth fall and drape over Suzanne! It probably looks blocky. That's fine — we're about to fix that.

More resolution = better folds

Select the cloth plane → Tab into Edit Mode → Right-click → Subdivide. Do this twice more. The mesh becomes a fine net. Tab back to Object Mode.

Test again

Press play. The cloth now folds and drapes way more realistically. Why? You just gave the simulator hundreds more vertices and springs to work with.

Open Modifiers

Click the Modifiers panel (the little wrench 🔧). This is where we add visual polish — without messing up the physics.

Smooth the surface

Right-click the cloth → Shade Auto Smooth. The harsh polygon edges blur out. The cloth instantly looks softer.

Add Subdivision Surface modifier

Add Modifier → Generate → Subdivision Surface. This smooths out the geometry visually without slowing the physics down.

Crank up Levels Viewport to 2

In the Subdivision modifier, set Levels Viewport = 2. The cloth now looks silky.

Test the simulation

Press Play one more time. Sit back. Watch your cloth fall like real fabric. You just built a physics simulation. 🎉

▎ 05 — Quick recap from Labs 13 & 14

Make it look like actual fabric.

A grey rectangle isn't cloth — it's just geometry. To sell the illusion, you need materials (how light hits the surface), shaders (the maths that controls that), and textures (the actual fabric pattern).

Materials

Open the Materials tab → + New. Tweak Base Color, Roughness (high for matte cotton, low for shiny silk), and Specular.

Shaders

Switch to the Shading workspace at the top of Blender. Drag in nodes like Image Texture, Bump, Mix Shader. Wire them into Principled BSDF.

Textures

Grab a free fabric texture from polyhaven.com or ambientcg.com. Plug the colour map into Base Color and the normal/bump map into Normal.

UV Unwrap

In Edit Mode → select all (A) → U → Smart UV Project. This tells Blender how to wrap your texture onto the cloth.
